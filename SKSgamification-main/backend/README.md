# Backend для SKS Gamification

Локальный backend на чистом Node.js. Он хранит данные в `backend/data/db.json`, поэтому прогресс не слетает после перезагрузки страницы и перезапуска frontend/backend.

## Запуск

Из корня проекта:

```bash
npm run backend
```

Или напрямую:

```bash
node backend/server.js
```

Сервер стартует на:

```text
http://localhost:3001
```

## Что хранится в `db.json`

- `users` — тестовые клиенты 50+, баланс, уровень, streak, опыт клуба;
- `quests` — ежедневные задания;
- `userProgress` — выполненные задания;
- `weeklyQuizzes` — еженедельные квизы;
- `weeklyQuizProgress` — история прохождения еженедельных квизов;
- `shopItems` — товары магазина бонусов;
- `redemptions` — обмены бонусов на товары;
- `leaderboard` — рейтинг пользователей;
- `transactions` — журнал бонусных операций / audit log.

## API

### Проверка сервера

```http
GET /api/health
```

### Пользователи

```http
GET /api/users
```

### Daily Check-in

```http
POST /api/daily-checkin
Content-Type: application/json

{
  "userId": "u50"
}
```

Логика:

- если пользователь заходит впервые за день — получает `+5` бонусов;
- если заходил вчера — `streak` увеличивается;
- если пропустил день — `streak` сбрасывается до `1`;
- повторный check-in в тот же день бонус не начисляет.

### Сегодняшние квесты

```http
GET /api/quests/today?userId=u50
```

Возвращает 3 квеста с учетом возраста пользователя. Награда считается с учетом клуба пользователя: чем выше клуб, тем выше множитель бонусов.

### Завершение квеста

```http
POST /api/quest/complete
Content-Type: application/json

{
  "userId": "u50",
  "questId": "q_water"
}
```

Логика:

- проверяет существование пользователя;
- проверяет существование квеста;
- проверяет возрастные ограничения;
- не дает выполнить один и тот же квест дважды за день;
- начисляет бонусы с учетом клубного множителя;
- добавляет опыт клуба;
- обновляет баланс, уровень, прогресс и лидерборд;
- пишет операцию в `transactions`.

### Еженедельный квиз

```http
GET /api/weekly-quiz?userId=u50
```

Возвращает квиз недели для пользователя. Квиз работает как задание, но дает больше бонусов и доступен только один раз в неделю.

```http
POST /api/weekly-quiz/complete
Content-Type: application/json

{
  "userId": "u50",
  "quizId": "wq_finance_safe",
  "answers": [1, 2, 0]
}
```

### Магазин бонусов

```http
GET /api/shop/items
```

Возвращает сертификаты партнеров, мерч и бонусные услуги. Остатки товаров не показываются пользователю в интерфейсе магазина.

```http
POST /api/shop/redeem
Content-Type: application/json

{
  "userId": "u50",
  "itemId": "shop_lombard_discount"
}
```

Логика:

- проверяет баланс пользователя;
- списывает бонусы;
- уменьшает остаток товара;
- создает запись в `redemptions`;
- пишет списание в `transactions`.

### Лига / клуб

```http
GET /api/club?userId=u50
```

Возвращает опыт пользователя, текущий клуб и множитель бонусов.

Клубные уровни:

| Клуб | Опыт | Множитель |
|---|---:|---:|
| Бронзовый клуб | от 0 XP | ×1 |
| Серебряный клуб | от 100 XP | ×1.1 |
| Золотой клуб | от 250 XP | ×1.2 |
| Платиновый клуб | от 500 XP | ×1.35 |

### Колесо удачи

```http
POST /api/wheel/spin
Content-Type: application/json

{
  "userId": "u50"
}
```

Призы выбираются случайно с весами вероятности:

| Приз | Вес |
|---|---:|
| +3 бонуса | 35 |
| +5 бонусов | 30 |
| +10 бонусов | 20 |
| +20 бонусов | 10 |
| джекпот +50 | 5 |

Пользователь может крутить колесо один раз в день.

### Лидерборд по бонусам

```http
GET /api/leaderboard
```

Возвращает рейтинг пользователей по балансу бонусов.

### Рейтинг по опыту

```http
GET /api/leaderboard/xp
```

Возвращает рейтинг пользователей по клубному опыту XP.

### История транзакций

```http
GET /api/transactions?userId=u50
```

## Что можно показать на демо

1. Переключить пользователя 50+.
2. Получить daily check-in.
3. Выполнить ежедневный квест.
4. Пройти еженедельный квиз.
5. Показать рост XP и повышение клуба.
6. Обменять бонусы в магазине.
7. Перезапустить backend и показать, что данные сохранились в `db.json`.
